#### The Reaction Quotient Q
The **reaction quotient Q** has the same mathematical form as the equilibrium expression but uses **current** (non-equilibrium) concentrations or partial pressures rather than equilibrium values. For aA + bB ⇌ cC + dD, the expression is Q = [C]^c [D]^d / ([A]^a [B]^b). Comparing Q to K tells you which direction the reaction must proceed to reach equilibrium.

#### Interpreting Q vs. K
- If **Q < K**: the numerator (products) is too small relative to the denominator (reactants), so the reaction shifts **right** (toward products) to increase Q until Q = K.
- If **Q > K**: the reaction shifts **left** (toward reactants) to decrease Q.
- If **Q = K**: the system is already at equilibrium and no net change occurs.

This comparison is the fastest way to predict shift direction on a competition problem.

#### Setting Up an ICE Table
An **ICE table** (Initial, Change, Equilibrium) organizes concentration changes systematically:

1. Write **Initial** concentrations or pressures for all species.
2. Define the **Change** row using a variable x, with stoichiometric coefficients applied (e.g., −x for reactants consumed, +x for products formed, scaled by molar ratios).
3. Express **Equilibrium** concentrations as Initial + Change.
4. Substitute into the K expression and solve for x.

For small K values (K < 10^−3), the **small-x approximation** (neglecting x in the denominator) is often valid; verify by confirming x < 5% of the initial concentration.

#### Solving ICE Table Problems
Consider H2(g) + I2(g) ⇌ 2HI(g), Kc = 49.0 at 458°C, with [H2]₀ = [I2]₀ = 0.100 M, [HI]₀ = 0. The ICE table gives equilibrium concentrations of [H2] = [I2] = 0.100 − x and [HI] = 2x. Substituting into Kc = (2x)^2 / (0.100 − x)^2 = 49.0 yields 2x / (0.100 − x) = 7.00, so x = 0.0778 M. Thus [HI] = 0.156 M at equilibrium.

#### Review Questions
1. For the reaction N2(g) + O2(g) ⇌ 2NO(g) with K = 1.0 × 10^−30 at 25°C, if [N2] = 0.80 M, [O2] = 0.20 M, and [NO] = 1.0 × 10^−16 M, calculate Q and determine the direction of shift.
2. Set up an ICE table for the reaction PCl5(g) ⇌ PCl3(g) + Cl2(g), Kc = 0.0400, starting with [PCl5]₀ = 0.200 M and no products. Write the equilibrium expression and the equation you would solve for x.
3. Under what conditions is the small-x approximation valid in an ICE table calculation, and what check should you perform after finding x?
