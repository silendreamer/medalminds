#### Multi-Step Stoichiometry Problem
Copper(II) oxide reacts with hydrogen gas: CuO + H₂ → Cu + H₂O. If 4.0 g of CuO reacts with 1.0 g H₂, which is limiting? CuO: molar mass 80 g/mol, so 4.0 g = 0.050 mol. H₂: molar mass 2 g/mol, so 1.0 g = 0.50 mol. Ratio needed is 1:1. You have 0.050 mol CuO and 0.50 mol H₂, so CuO is limiting. Copper produced: 0.050 mol Cu = 3.2 g.

#### Reaction Type Identification
- 2KClO₃ → 2KCl + 3O₂: decomposition (heat applied)
- Mg + O₂ → MgO: synthesis
- C₃H₈ + O₂ → CO₂ + H₂O: combustion
- Fe + AgNO₃ → Fe(NO₃)₂ + Ag: single displacement
- NaCl + AgNO₃ → AgCl + NaNO₃: double displacement (precipitation)

#### Review Questions
1. Classify this reaction and balance it: Cu + HNO₃ → Cu(NO₃)₂ + NO + H₂O
2. In the reaction 2Al + 3Br₂ → 2AlBr₃, if you have 5.0 g Al and 10.0 g Br₂, which is limiting?
3. If 18 g of glucose (C₆H₁₂O₆) should produce 26.4 g of ethanol (C₂H₅OH) via fermentation, but only 20 g is produced, what's the percent yield?
