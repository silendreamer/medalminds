#### Rapid Name/Formula Drill
Name these: BaO, Fe(OH)₃, N₂O, HNO₂(aq), Cu₂S, K₂Cr₂O₇, SF₄
- BaO → barium oxide
- Fe(OH)₃ → iron(III) hydroxide
- N₂O → dinitrogen monoxide
- HNO₂(aq) → nitrous acid
- Cu₂S → copper(I) sulfide
- K₂Cr₂O₇ → potassium dichromate
- SF₄ → sulfur tetrafluoride

Write formulas: manganese(II) chloride → MnCl₂; sulfurous acid → H₂SO₃; tetraphosphorus decoxide → P₄O₁₀

#### Review Questions
1. Name: PbSO₄, N₂F₂, HClO, (NH₄)₃PO₄.
2. Write formulas for: dinitrogen tetroxide, iron(II) carbonate, hydrobromic acid.
3. A student writes "iron sulfate" without a Roman numeral. Explain why this name is ambiguous and how to fix it.
