#### How Scientific Inquiry Questions Are Structured
Bowl questions about scientific method typically give a scenario and ask you to classify or calculate. They often start with a general setup ("A chemist is testing…"), then give the key clue ("…where she changes only the temperature…"), then ask the question ("…what is the name of the variable she is changing?"). Your goal: recognize the clue before the question is asked.

#### 10 Interrupt-Level Practice Clues
1. "…describes how close a measurement is to the true, accepted value…" → BUZZ: **accuracy**
2. "…when a balance reads 0.5 g before any sample is placed on it, this is an example of…" → BUZZ: **systematic error**
3. "…the group in an experiment that does not receive the experimental treatment is called…" → BUZZ: **control group**
4. "…calculated by dividing the absolute difference between experimental and accepted values by the accepted value and multiplying by 100…" → BUZZ: **percent error**
5. "…a prediction that can be tested and proven false is called a…" → BUZZ: **hypothesis** (also accept: falsifiable hypothesis)
6. "…error that can be reduced by averaging more trials is called…" → BUZZ: **random error**
7. "…uses a sealed pressurized vessel to prevent heat loss in combustion experiments…" → BUZZ: **bomb calorimeter**
8. "…the process by which experts evaluate a paper before journal publication is called…" → BUZZ: **peer review**
9. "…in an experiment, the variable that is measured in response to changes is called…" → BUZZ: **dependent variable**
10. "…scatter in measurements caused by uncontrollable environmental variation is an example of…" → BUZZ: **random error**

#### Review Questions
1. A toss-up begins: "This type of variable is held constant throughout an experiment to prevent it from affecting the results…" What do you buzz with?
2. Distinguish between the earliest buzz point and the safe buzz point for a toss-up about "systematic error."
3. Write your own 3-clue toss-up for the concept "percent error," ordered from hardest to easiest clue.
