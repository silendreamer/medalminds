#### Accuracy vs. Precision: A Critical Distinction
**Accuracy** describes how close a measurement is to the true value. **Precision** describes how reproducible a measurement is — how close repeated measurements are to each other. These are independent: you can be precise but inaccurate (consistently measuring 4.82 g when true mass is 5.00 g — systematic error), accurate but imprecise (one trial gives 4.9, another 5.1, another 5.0 — random error), both, or neither.

#### Types of Error
**Systematic (determinate) error** shifts all measurements in the same direction — always too high or always too low. Causes: uncalibrated balance, consistently misreading a meniscus, using a thermometer that reads 2°C too high. Systematic error cannot be reduced by more trials. **Random (indeterminate) error** causes scatter in both directions. Causes: environmental fluctuations, slight technique variations. Random error can be reduced by averaging more trials.

#### Percent Error
Percent error quantifies accuracy: %error = |experimental − theoretical| / theoretical × 100%. A student measures the density of aluminum as 2.58 g/cm³; the accepted value is 2.70 g/cm³. Percent error = |2.58 − 2.70| / 2.70 × 100% = 4.44%. Lower percent error means more accurate results.

#### Identifying Error Sources in Chemistry
Common systematic errors in chemistry labs: reading a graduated cylinder from the wrong angle (parallax error), not zeroing a balance before use (tare error), heat loss to environment in calorimetry, incomplete reactions. When asked to "identify a source of error," always describe HOW it would affect the result (would it make your value too high or too low?), not just that it exists.

#### Science Bowl Clue
Precision relates to consistency; accuracy relates to correctness. If a question describes multiple measurements that cluster tightly together but differ from the known value, that's high precision, low accuracy — systematic error. If measurements scatter widely but average near the true value, that's low precision but reasonable accuracy — random error.

#### Review Questions
1. A student measures the boiling point of ethanol as 79.1°C, 79.0°C, and 79.2°C. The accepted value is 78.4°C. Are these results precise? Accurate? What type of error is present?
2. Calculate the percent error if a student determines the molar mass of NaCl to be 59.5 g/mol (accepted: 58.44 g/mol).
3. How does averaging multiple trials reduce random error but not systematic error?
