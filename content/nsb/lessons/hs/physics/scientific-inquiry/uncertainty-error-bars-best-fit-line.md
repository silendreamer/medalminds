#### What Error Bars Mean
Error bars extend above and below each data point by ± the uncertainty. If error bars on y use ±Δy, the true value lies within that bar with ~68% confidence (one standard deviation). Overlapping error bars between two conditions suggests the difference may not be statistically significant.

#### Drawing a Line of Best Fit
The best-fit line minimizes the total squared distance from all points to the line (least-squares method). It should pass through the middle of the data, with roughly equal points above and below. It does NOT need to go through any specific point, including the origin, unless physics demands it.

#### Slope and Its Uncertainty
Extract slope from the best-fit line using two points far apart on the line (not data points). Calculate maximum and minimum slopes from the range of reasonable fit lines within the error bars. Report slope ± uncertainty.

#### Residuals
A residual = (measured y) − (predicted y from line). Plot residuals vs. x. If residuals are random, the linear model fits. If residuals show a pattern (curve, oscillation), the model is wrong — you need a different functional form.

#### Review Questions
1. What does it mean if two data points have overlapping error bars?
2. How do you determine if a linear model is appropriate from a residual plot?
