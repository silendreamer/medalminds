#### The Seven Base Units
The SI system has seven base units: meter (m) for length, kilogram (kg) for mass, second (s) for time, ampere (A) for electric current, kelvin (K) for temperature, mole (mol) for amount of substance, and candela (cd) for luminous intensity. Everything else — newtons, joules, watts, pascals — is derived from these seven.

#### Derived Units
A newton (N) = kg·m/s². A joule (J) = kg·m²/s² = N·m. A watt (W) = J/s = kg·m²/s³. A pascal (Pa) = N/m² = kg/(m·s²). Understanding derivations lets you check equations: if both sides have the same units, the equation is dimensionally consistent.

#### SI Prefixes
Key prefixes: nano (n) = 10⁻⁹, micro (μ) = 10⁻⁶, milli (m) = 10⁻³, centi (c) = 10⁻², kilo (k) = 10³, mega (M) = 10⁶, giga (G) = 10⁹. Example: 500 nm = 500 × 10⁻⁹ m = 5 × 10⁻⁷ m. This is the wavelength of visible (green) light.

#### Why Units Matter
Units prevent disasters. In 1999, NASA's Mars Climate Orbiter was lost because one team used pound-force·seconds and another used newton·seconds. Always carry units through every calculation; they'll catch errors that numbers alone miss.
