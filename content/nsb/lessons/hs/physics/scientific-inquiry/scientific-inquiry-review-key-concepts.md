#### 15 Must-Know Facts
1. Independent variable = what you change; dependent variable = what you measure.
2. A control group receives no treatment.
3. Systematic error shifts all measurements the same direction; random error scatters them.
4. Accuracy = closeness to true value; precision = closeness of repeated measurements to each other.
5. Percent error = |exp − theo| / theo × 100%.
6. Sig figs in multiplication/division: use fewest sig figs in inputs.
7. Leading zeros are never significant (0.0034 has 2 sig figs).
8. A hypothesis must be falsifiable (testable and potentially disprovable).
9. Error bars on graphs represent measurement uncertainty.
10. Reproducibility = same result in different labs; repeatability = same experimenter, same lab.
11. Controlled variables are held constant to isolate the independent variable.
12. Averaging multiple trials reduces random error but not systematic error.
13. Uncertainty is written as value ± uncertainty.
14. Scientific consensus requires multiple independent replications.
15. Confounding variable = an uncontrolled factor that affects the dependent variable.

#### Common Bowl Traps
- Don't confuse "accurate but not precise" (scattered near the true value) with "precise but not accurate" (clustered away from true value).
- Percent error always uses the theoretical value in the denominator.
- "Proving" a hypothesis is not possible — you can only support or fail to refute it.

#### Review Questions
1. A student measures a mass as 52.3, 52.3, and 52.3 g, but the true mass is 48.0 g. Is this precise? Accurate? Explain.
2. In an experiment, the independent variable is changed while the ______ variable is measured.
3. Calculate percent error if the experimental value is 150 m/s and the theoretical value is 160 m/s.
