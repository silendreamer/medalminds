### Introduction to Functions

Functions are fundamental concepts in mathematics that describe relationships between sets of inputs and outputs. A function assigns exactly one output for each input from a specified set called the domain. Understanding functions is crucial for solving equations, analyzing graphs, and applying mathematical concepts in real-world scenarios.

### Function Notation

Function notation is a way to represent functions mathematically, typically using the format \( f(x) \), where \( f \) denotes the function and \( x \) is the input variable. For example, if \( f(x) = 2x + 3 \), then for any value of \( x \), you can calculate the corresponding output. This notation allows for clear communication of mathematical ideas and is essential for working with multiple functions simultaneously.

### Domain and Range

The domain of a function is the complete set of possible input values (or \( x \)-values) that the function can accept, while the range is the set of possible output values (or \( y \)-values) resulting from those inputs. For instance, in the function \( f(x) = \sqrt{x} \), the domain is all non-negative real numbers since the square root of a negative number is not defined in the set of real numbers. Understanding the domain and range helps in graphing functions and determining their behavior.

### Types of Functions

Functions can be classified into various types based on their characteristics. Linear functions, for example, have the form \( f(x) = mx + b \), where \( m \) and \( b \) are constants, and their graphs are straight lines. Other types include quadratic functions, which are represented by \( f(x) = ax^2 + bx + c \) and produce parabolic graphs, and exponential functions, which grow rapidly and have the form \( f(x) = a \cdot b^x \).

### Identifying Functions

To determine whether a relation is a function, the vertical line test can be applied: if a vertical line intersects the graph of the relation at more than one point, it is not a function. Additionally, a function can be represented in various forms, including tables, graphs, and equations, each providing unique insights into its properties. Recognizing functions in different representations is essential for problem-solving in mathematics.

### Composite Functions

Composite functions involve combining two functions, where the output of one function becomes the input of another. This is denoted as \( (f \circ g)(x) = f(g(x)) \). For example, if \( f(x) = 2x \) and \( g(x) = x + 1 \), then the composite function \( (f \circ g)(x) = f(g(x)) = 2(x + 1) = 2x + 2 \). Understanding how to work with composite functions is vital for advanced mathematical applications.

### Review Questions

2. How would you express the function \( g(x) = x^2 + 4 \) in function notation?
3. If a vertical line intersects the graph of a relation at two points, what can you conclude about that relation?
