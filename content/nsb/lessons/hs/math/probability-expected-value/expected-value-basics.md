### Introduction to Expected Value

Expected value (EV) is a fundamental concept in probability and statistics that provides a measure of the center of a probability distribution. It represents the average outcome of a random variable when an experiment is repeated many times. Understanding expected value is crucial for making informed decisions in uncertain situations, such as games of chance, investments, and various real-world applications.

### Discrete Random Variables

A discrete random variable is a type of variable that can take on a countable number of distinct values. Examples include the roll of a die, the number of heads in a series of coin flips, or the score in a game. The probability distribution of a discrete random variable assigns probabilities to each possible value, ensuring that the sum of all probabilities equals one.

### Calculating Expected Value

To calculate the expected value of a discrete random variable, you multiply each possible outcome by its corresponding probability and then sum these products. Mathematically, this is expressed as:  
\[ E(X) = \sum (x_i \cdot P(x_i)) \]  
where \( x_i \) represents each possible outcome and \( P(x_i) \) is the probability of that outcome. This formula allows us to find a weighted average, where outcomes with higher probabilities contribute more significantly to the expected value.

### Significance of Expected Value

The expected value provides insight into the long-term average result of random processes. It helps in decision-making by allowing individuals to compare different scenarios based on their potential outcomes. For instance, in gambling, players can use expected value to determine whether a game is favorable or unfavorable based on the odds and payouts.

### Examples of Expected Value

Consider a simple game where you roll a fair six-sided die. The possible outcomes are 1 through 6, each with a probability of \( \frac{1}{6} \). The expected value can be calculated as follows:  
\[ E(X) = (1 \cdot \frac{1}{6}) + (2 \cdot \frac{1}{6}) + (3 \cdot \frac{1}{6}) + (4 \cdot \frac{1}{6}) + (5 \cdot \frac{1}{6}) + (6 \cdot \frac{1}{6}) = 3.5 \]  
This means that over many rolls, the average result will approach 3.5.

### Applications of Expected Value

Expected value is widely used in various fields, including finance, insurance, and economics. In finance, investors calculate the expected return on an investment to assess its potential profitability. In insurance, companies use expected value to determine premiums by evaluating the likelihood and cost of claims.
