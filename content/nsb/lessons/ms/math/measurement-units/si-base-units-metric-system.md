#### Why Scientists Use the SI System

The **SI system** (Système International, the modern metric system) is the standard set of units scientists use everywhere in the world. Using one shared system means measurements can be compared and combined without confusion. Science Bowl rewards instant recall of which unit goes with which quantity, so these are easy, fast points.

#### The Seven SI Base Units

Every other unit is built from these seven **base units**:

1. **meter (m)** — length
2. **kilogram (kg)** — mass *(note: the base unit is the kilogram, not the gram)*
3. **second (s)** — time
4. **kelvin (K)** — temperature
5. **ampere (A)** — electric current
6. **mole (mol)** — amount of substance
7. **candela (cd)** — luminous intensity

A common memory hook: "**K**ind **M**en **S**hould **M**ake **A**ll **C**andy **C**ount" or simply drill the pairs: mass→kg, temperature→kelvin, current→ampere.

#### Base Units vs. Derived Units

A **derived unit** is made by combining base units. For example:
- **Liter (L)** and **square meter (m²)** come from length.
- **Newton (N)** = kg·m/s² (force).
- **Joule (J)** = N·m = kg·m²/s² (energy).
- **Watt (W)** = J/s (power).

If a question asks for the **base unit** of a quantity, the answer is one of the seven above — a liter or a joule is **not** a base unit. Knowing this distinction prevents a classic buzzer mistake.

#### Temperature: A Special Note

The SI base unit of temperature is the **kelvin**, not the degree Celsius. Kelvin starts at **absolute zero** (0 K = −273.15 °C), the coldest possible temperature. To convert: **K = °C + 273.15**. A kelvin and a Celsius degree are the same size, so a 10 °C change equals a 10 K change.
