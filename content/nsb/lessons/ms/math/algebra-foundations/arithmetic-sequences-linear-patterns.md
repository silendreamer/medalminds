#### What Is an Arithmetic Sequence?
A sequence where consecutive terms differ by a constant amount (the common difference d). Examples: 3, 7, 11, 15, 19 (d = 4); 20, 15, 10, 5 (d = −5). To find d: subtract any term from the next: d = aₙ₊₁ − aₙ. An arithmetic sequence is just a linear function evaluated at whole-number inputs.

#### The nth Term Formula
aₙ = a₁ + (n−1)d, where a₁ = first term, d = common difference, n = term number. Find the 20th term of 3, 7, 11, 15: a₁ = 3, d = 4. a₂₀ = 3 + (20−1)(4) = 3 + 76 = 79. Alternatively: each term adds 4 to the previous. Term 1 is 3, term 2 is 7 = 3+4, term n is 3 + 4(n−1). Graph aₙ vs. n: straight line with slope d.

#### Arithmetic Series: Summing the Terms
Sum of first n terms: Sₙ = n/2 × (a₁ + aₙ) = n/2 × (first + last). Sum of 1+2+3+…+100: n=100, a₁=1, a₁₀₀=100. S₁₀₀ = 100/2 × (1+100) = 50 × 101 = **5050** (Gauss's famous formula). This pairing technique — match first with last, second with second-to-last, etc. — always gives the same sum (a₁ + aₙ).

#### Geometric Sequences (Comparison)
Arithmetic: add constant. Geometric: multiply by constant (ratio r). 2, 6, 18, 54 (r = 3). 100, 50, 25, 12.5 (r = 1/2). nth term: aₙ = a₁ × rⁿ⁻¹. Recognizing whether a pattern is arithmetic or geometric is a frequent Science Bowl question.

#### Pattern Recognition
Is it arithmetic, geometric, or neither?
- 5, 9, 13, 17: differences are +4 → arithmetic, d = 4
- 3, 6, 12, 24: ratios are ×2 → geometric, r = 2
- 1, 4, 9, 16: squares — neither arithmetic nor geometric
- 1, 1, 2, 3, 5, 8: Fibonacci (each term = sum of previous two) — neither

#### Review Questions
1. Find the 15th term of the arithmetic sequence 5, 8, 11, 14, …
2. Find the sum 1 + 3 + 5 + … + 99 (first 50 odd numbers).
3. Is 2, 4, 8, 16 arithmetic, geometric, or neither?
