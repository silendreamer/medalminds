#### Variables on Both Sides
5x − 3 = 2x + 9: collect variable terms on one side. Subtract 2x from both: 3x − 3 = 9. Add 3: 3x = 12. Divide by 3: x = 4. Strategy: move all variable terms to one side (usually the side with the larger coefficient), then all constants to the other.

#### The Distributive Property in Equations
First, distribute to remove parentheses: 3(x − 4) = 2x + 5 → 3x − 12 = 2x + 5 → x = 17. Always distribute before collecting terms. 2(3x + 1) − x = 4(x − 2): → 6x + 2 − x = 4x − 8 → 5x + 2 = 4x − 8 → x = −10.

#### Special Case: No Solution
Solve: 3x + 5 = 3x − 2. Subtract 3x: 5 = −2. This is FALSE and never true for any x. The equation has NO SOLUTION. This happens when the equation represents two parallel lines — they never intersect.

#### Special Case: All Real Numbers (Identity)
Solve: 2(x + 3) = 2x + 6. Distribute: 2x + 6 = 2x + 6. Subtract 2x: 6 = 6. TRUE for all x. Every real number is a solution. This represents the same line twice. Called an identity.

#### Strategy for Complex Equations
1. Distribute and simplify each side
2. Collect variable terms on one side
3. Collect constant terms on the other
4. Divide by the coefficient
5. Check by substitution

#### Review Questions
1. Solve: 7x − 2 = 4x + 13.
2. Solve: 4(x + 2) = 2x + 14.
3. Solve: 5x + 3 = 5x − 7. What kind of equation is this?
