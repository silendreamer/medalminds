#### 15 Key Facts
1. A function assigns exactly one output to each input
2. Vertical line test: passes the test → it's a function
3. f(x) notation: f(3) means substitute x = 3
4. Domain = set of allowed inputs; range = set of outputs
5. Arithmetic sequence: constant difference d between terms
6. nth term of arithmetic: aₙ = a₁ + (n−1)d
7. Sum of arithmetic sequence: Sₙ = n(a₁ + aₙ)/2
8. 1 + 2 + ... + n = n(n+1)/2
9. Geometric sequence: constant ratio r between terms
10. nth term of geometric: aₙ = a₁ × rⁿ⁻¹
11. If r > 1: geometric sequence grows; if 0 < r < 1: it shrinks
12. Linear function → arithmetic sequence at whole-number inputs
13. Exponential function → geometric sequence
14. Neither arithmetic nor geometric: squares (1,4,9,16), Fibonacci (1,1,2,3,5)
15. Function rule from table: find the pattern in differences or ratios

#### Speed Drill
1. If f(x) = 2x² − 5, find f(3).
2. Is 4, 8, 12, 16 arithmetic or geometric?
3. Find the sum 2 + 4 + 6 + ... + 20.
4. What is the 7th term of 1, 3, 9, 27, …?
5. Does {(1,2), (3,4), (3,6)} represent a function?

#### Review Questions
1. Write the explicit formula for the sequence: 100, 95, 90, 85, … Find the 30th term.
2. A function f is defined so that f(n) = 3f(n−1) and f(1) = 2. Find f(4).
3. How can you tell from a table whether a sequence is arithmetic, geometric, or neither?
