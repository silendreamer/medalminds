#### 20 Key Algebra Facts
1. An equation stays balanced if you do the same thing to both sides
2. Inverse of addition is subtraction; inverse of multiplication is division
3. To isolate x: undo the operations in reverse PEMDAS order
4. Always distribute before collecting terms
5. Move variable terms to the side with the larger coefficient
6. Like terms have the same variable and same exponent
7. Coefficient is the number multiplied by the variable
8. 3x − x = 2x (not 3)
9. −1 × (a + b) = −a − b (not −a + b)
10. If solving gives a FALSE statement (5 = 2), no solution exists
11. If solving gives a TRUE statement (6 = 6), infinite solutions (identity)
12. "A number 3 more than twice x" → 2x + 3 (not 3 + 2x — same, but read carefully)
13. "5 less than x" → x − 5 (NOT 5 − x)
14. Consecutive integers: n, n+1, n+2
15. Consecutive odd/even integers: n, n+2, n+4
16. Sum of angles in a triangle = 180° (useful for angle equation problems)
17. Always check your answer by substituting back
18. The distributive property: a(b+c) = ab + ac
19. x/a = b → x = ab (multiply both sides by a)
20. ax + b = cx + d → (a−c)x = d−b

#### Speed Drill — Under 20 Seconds Each
1. Solve: 3x + 4 = 19.
2. Solve: 5 − 2x = 11.
3. Solve: 4(x − 3) = 8.
4. Are 4x, 4y, x, x² all like terms? Which ones can be combined?
5. Evaluate 3x² − 5x + 1 for x = −1.

#### Review Questions
1. Write an equation for: "Seven more than three times a number equals twenty-five."
2. Solve: 6x − 4 = 4x + 10.
3. A trapezoid has parallel sides of x and 2x + 3, and two other sides of 5 each. Its perimeter is 38. Find x.
