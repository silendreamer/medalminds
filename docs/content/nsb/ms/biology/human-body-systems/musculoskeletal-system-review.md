#### Must-Know Pairs
- Compact bone: dense outer layer; Spongy bone: lattice inner layer
- Red marrow: blood cell production (flat bones); Yellow marrow: fat storage (long bone shafts)
- Osteoblasts: build bone; Osteoclasts: break down bone
- Sarcomere: basic contractile unit; Actin + Myosin = contractile proteins
- Ca²⁺: triggers muscle contraction; ATP: powers the power stroke
- Tendons: muscle → bone; Ligaments: bone → bone
- Sprain: ligament injury; Strain: muscle/tendon injury
- Cartilage: cushions joints, avascular (heals slowly)

#### Sliding Filament Theory — 5-Step Summary
1. Motor neuron releases acetylcholine → muscle fiber depolarizes
2. Ca²⁺ released from sarcoplasmic reticulum
3. Ca²⁺ exposes actin binding sites
4. Myosin heads attach to actin; power stroke (uses ATP) shortens sarcomere
5. Sarcomere shortens → muscle fiber shortens → muscle contracts

#### Joint Types Quick Reference
- Ball-and-socket: hip, shoulder → most mobile (rotation)
- Hinge: knee, elbow → one plane (flexion/extension)
- Pivot: neck (atlas-axis) → rotation
- Immovable: skull sutures
