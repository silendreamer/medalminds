#### How the Periodic Table Is Organized
The periodic table arranges all 118 known elements in order of increasing **atomic number** (number of protons). It's arranged in:
- **Periods** (rows): 7 periods, numbered 1–7. Elements in the same period have the same number of electron shells.
- **Groups** (columns): 18 groups, numbered 1–18 (or IA–VIIIA in the older system). Elements in the same group have the same number of valence electrons and similar chemical properties.

#### What's in Each Element Box?
Typically:
- **Atomic number** (top): number of protons
- **Chemical symbol** (middle): 1–2 letter abbreviation
- **Element name** (below symbol)
- **Atomic mass** (bottom): weighted average mass in amu

#### Periods and What They Tell Us
- Period 1: H and He (1 electron shell)
- Period 2: Li through Ne (2 shells)
- Period 3: Na through Ar (3 shells)
As you move down the table, each period adds one more electron shell, making atoms larger.

#### Groups and Properties
- Group 1 (Alkali metals): Li, Na, K, Rb, Cs, Fr — very reactive metals
- Group 2 (Alkaline earth metals): Be, Mg, Ca, Sr, Ba, Ra — reactive metals
- Groups 3–12 (Transition metals): Fe, Cu, Zn, Ag, Au, etc.
- Group 17 (Halogens): F, Cl, Br, I, At — very reactive nonmetals
- Group 18 (Noble gases): He, Ne, Ar, Kr, Xe, Rn — nearly inert
