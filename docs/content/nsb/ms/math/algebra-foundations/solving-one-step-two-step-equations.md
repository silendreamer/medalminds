#### The Balance Principle
An equation is like a balance scale — both sides are equal. Any operation you do to one side, you must do to the other. This is the ONLY rule of algebra: maintain equality by doing the same thing to both sides. Everything else follows from this.

#### Inverse Operations
Each operation has an inverse: addition ↔ subtraction, multiplication ↔ division, squaring ↔ square root. To isolate a variable, undo each operation applied to it using its inverse. Isolating x means getting x alone on one side.

#### One-Step Equations
- x + 7 = 15: subtract 7 from both sides → x = 8
- x − 4 = 9: add 4 to both sides → x = 13
- 3x = 21: divide both sides by 3 → x = 7
- x/5 = 6: multiply both sides by 5 → x = 30

Always check by substituting the answer back into the original equation.

#### Two-Step Equations
"Undo" operations in reverse order of PEMDAS — generally, undo addition/subtraction first, then multiplication/division. 2x + 5 = 17: subtract 5 → 2x = 12; divide by 2 → x = 6. Check: 2(6) + 5 = 17 ✓.

Negative coefficients: −3x + 4 = 13 → subtract 4: −3x = 9 → divide by −3: x = −3. Check: −3(−3) + 4 = 9 + 4 = 13 ✓.

#### Equations with Fractions
x/3 − 2 = 4: add 2 first → x/3 = 6; multiply by 3 → x = 18. Or: multiply every term by the LCD first to eliminate fractions. x/2 + x/3 = 5: LCD = 6; multiply through: 3x + 2x = 30 → 5x = 30 → x = 6.

#### Review Questions
1. Solve: 4x − 9 = 23.
2. Solve: x/6 + 3 = 7.
3. Solve: −2x + 11 = 3. Check your answer.
