#### 20 Key Facts
1. Slope = (y₂ − y₁)/(x₂ − x₁) = rise/run
2. Positive slope: line goes up left to right
3. Negative slope: line goes down left to right
4. Zero slope: horizontal line (y = constant)
5. Undefined slope: vertical line (x = constant)
6. Slope-intercept form: y = mx + b (m = slope, b = y-intercept)
7. Standard form: Ax + By = C
8. Point-slope form: y − y₁ = m(x − x₁)
9. Parallel lines: equal slopes, different intercepts
10. Perpendicular lines: slopes are negative reciprocals (product = −1)
11. To find y-intercept: set x = 0
12. To find x-intercept: set y = 0
13. Inequality flip: multiply/divide by negative → flip the sign
14. Open circle on graph: strict inequality (< or >)
15. Closed circle on graph: non-strict (≤ or ≥)
16. "At least" → ≥; "at most" → ≤; "more than" → >; "less than" → <
17. Compound AND: −3 < x < 5 (between, segment on number line)
18. Compound OR: x < −1 or x > 4 (two rays)
19. Slope of x-axis (y = 0): 0
20. Every nonvertical line crosses the y-axis at exactly one point

#### Speed Drill
1. What is the slope through (0,0) and (4,12)?
2. Is y = 5 a horizontal or vertical line?
3. What is the negative reciprocal of 2/3?
4. Solve: −3x ≥ 9.
5. Find the x-intercept of y = 2x − 8.

#### Review Questions
1. Write the equation of the line through (3, −1) and (6, 5) in slope-intercept form.
2. For what values of x is 3x + 4 > 2x − 1?
3. A store makes profit P = 5x − 200, where x is items sold. How many items must be sold to make a profit?
