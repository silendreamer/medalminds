#### The Translation Step
English phrases → algebra:
- "is," "equals," "is the same as" → =
- "more than," "increased by," "sum of" → +
- "less than," "decreased by," "difference" → −
- "times," "product of," "of" → ×
- "divided by," "quotient of," "per" → ÷
- "a number," "some amount" → variable (x)

#### Problem Type 1: Age Problems
"Maria is 4 years older than twice her brother's age. Maria is 22. How old is her brother?" Let b = brother's age. 2b + 4 = 22 → 2b = 18 → b = 9. Check: 2(9) + 4 = 22 ✓.

#### Problem Type 2: Consecutive Integer Problems
"Find three consecutive integers whose sum is 48." Let n, n+1, n+2 be the integers. n + (n+1) + (n+2) = 48 → 3n + 3 = 48 → 3n = 45 → n = 15. Integers: 15, 16, 17. Check: 15+16+17 = 48 ✓.

#### Problem Type 3: Cost and Revenue
"A store sells notebooks for $2 each and pens for $1.50 each. If a student buys 5 notebooks and some pens and spends $16 total, how many pens?" Let p = pens. 2(5) + 1.50p = 16 → 10 + 1.50p = 16 → 1.50p = 6 → p = 4 pens.

#### Problem Type 4: Number Relationships
"One number is 3 times another. Their sum is 52. Find both numbers." Let x = smaller. Larger = 3x. x + 3x = 52 → 4x = 52 → x = 13, larger = 39. Check: 13 + 39 = 52 ✓.

#### Review Questions
1. The sum of three consecutive odd integers is 57. Find them.
2. Tickets cost $5 for adults and $3 for children. 200 tickets were sold for a total of $780. How many adult tickets were sold?
3. A number increased by 7 is the same as three times the number decreased by 5. Find the number.
