#### Interpreting Linear Models
A taxi charges $2.50 base fare plus $1.80 per mile. Cost equation: C = 1.80m + 2.50. Here, slope = $1.80/mile (rate), y-intercept = $2.50 (starting cost before any miles). Given C = 11.50: 1.80m + 2.50 = 11.50 → 1.80m = 9.00 → m = 5 miles.

#### Budget Constraints
"A student has $30 to spend on notebooks ($4 each) and pens ($1.50 each). She buys 3 notebooks. Write an inequality for the number of pens she can buy." 4(3) + 1.50p ≤ 30 → 12 + 1.50p ≤ 30 → 1.50p ≤ 18 → p ≤ 12. She can buy at most 12 pens.

#### Finding Intersection Points
"At what mileage do two taxi companies charge the same?" Company A: 2m + 3. Company B: 1.5m + 5. Set equal: 2m + 3 = 1.5m + 5 → 0.5m = 2 → m = 4 miles. At 4 miles, both cost $11. For > 4 miles, compare to see which is cheaper.

#### Temperature Conversion
F = (9/5)C + 32 relates Fahrenheit and Celsius. This is a linear equation with slope 9/5 and y-intercept 32. At what Celsius temperature does F = C? Set (9/5)C + 32 = C → 32 = C − (9/5)C = −(4/5)C → C = −40. At −40 degrees, Fahrenheit and Celsius are equal.

#### Science Bowl Signal Words for Inequalities
"At least" → ≥. "No more than" → ≤. "Less than" → <. "More than" → >. "Between" → two-sided inequality (check whether endpoints are included). "Cannot exceed" → ≤.

#### Review Questions
1. A phone plan charges $20/month plus $0.05/text. Write an equation for total cost. If the budget is $35/month, write and solve an inequality for maximum texts.
2. When do y = 3x + 1 and y = x + 7 intersect?
3. A runner trains at 8 min/mile. Write a function for total time in minutes vs. miles run. How many miles if the run takes under 40 minutes?
