#### What Makes Something a Function
A function is a rule that assigns exactly one output to each input. "Each x gets exactly one y." A vending machine is a perfect analogy: one button press → one specific item (not a random assortment). If one input could give two different outputs, it's NOT a function.

#### The Vertical Line Test
Graph a relation. Draw vertical lines across the graph. If any vertical line crosses the graph more than once, it's NOT a function (one x-value gives multiple y-values). A circle fails the vertical line test. A parabola opening up or down passes it.

#### Function Notation: f(x)
Instead of writing y, we write f(x) — read "f of x." This names the function (f) and shows the input (x). f(x) = 3x − 2: f(4) means "substitute 4 for x" → 3(4) − 2 = 10. So f(4) = 10. The notation makes it clear you're evaluating the function at a specific input value.

#### Domain and Range
Domain: all possible input values (x). Range: all resulting output values (y, or f(x)). For f(x) = 2x + 1 with no restrictions: domain = all real numbers; range = all real numbers. For a function with a table of values, the domain is the set of x-values listed, range is the set of y-values.

#### Representing Functions
Functions can be given as equations, tables, graphs, or mapping diagrams. All four representations are equivalent. Moving between them is an essential algebra skill. Table to equation: if x doubles, does y also double? Does y = 2x work for all pairs?

#### Review Questions
1. If f(x) = x² − 3x + 1, find f(2) and f(−1).
2. Is the set {(1,2), (2,3), (2,5), (4,6)} a function? Why or why not?
3. What is the domain of f(x) = 5/(x − 3)?
