#### Building Functions from Situations
A car rental costs $30/day plus $0.15/mile. Cost as a function of miles: C(m) = 0.15m + 30. Evaluate for 200 miles: C(200) = 0.15(200) + 30 = 30 + 30 = $60. How many miles if cost = $45? 0.15m + 30 = 45 → 0.15m = 15 → m = 100 miles. Function notation C(m) clarifies the input (m = miles) and output (C = cost).

#### Finding Function Rules from Tables
| x | y |
|---|---|
| 1 | 5 |
| 2 | 8 |
| 3 | 11 |
| 4 | 14 |
Difference in y: +3 each time → arithmetic (linear). Find the rule: y = 3x + 2 (check: 3(1)+2=5 ✓). This is f(x) = 3x + 2.

#### Geometric Growth in Context
A savings account doubles every 5 years. Starting with $500, value after n periods: V(n) = 500 × 2ⁿ. After 3 periods (15 years): V(3) = 500 × 8 = $4,000. This is exponential growth — grows much faster than linear. Science Bowl energy questions often involve exponential functions.

#### Predicting Future Terms
"A bacteria culture doubles every hour. At t = 0, there are 100 bacteria. How many at t = 8 hours?" Geometric: aₙ = 100 × 2ⁿ. At t = 8: 100 × 2⁸ = 100 × 256 = 25,600. Note: n is the number of doublings, which equals t in this case since doubling occurs every 1 hour.

#### Science Bowl Pattern Clues
"The nth term of a sequence is…" → evaluate the formula for specific n. "What is the 10th term of…" → find the pattern (arithmetic, geometric, or formula), apply. "At this rate, when will…" → set the function equal to the target value, solve for n.

#### Review Questions
1. A sequence has first term 7 and common difference 5. Write the nth term formula and find the 25th term.
2. A function is defined by f(x) = x² + 1. Make a table for x = 0, 1, 2, 3, 4. Is this arithmetic, geometric, or neither?
3. A population of 1000 doubles every year. Write a function for population after n years. When does it first exceed 10,000?
