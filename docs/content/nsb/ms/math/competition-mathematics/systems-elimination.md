#### Substitution Method
System: y = 2x + 1 and x + y = 10. Substitute the first into the second: x + (2x + 1) = 10, so 3x = 9, x = 3. Then y = 2(3) + 1 = 7. Solution: (3, 7).

#### Elimination Method
System: 2x + 3y = 13 and x - 2y = 0. Multiply the second by 2: 2x - 4y = 0. Subtract from the first: (2x + 3y) - (2x - 4y) = 13 - 0, so 7y = 13, y = 13/7. Then x = 2y = 26/7. Solution: (26/7, 13/7).

#### When Systems Have No Solution or Infinite Solutions
If the equations represent parallel lines, no solution exists (inconsistent). If they represent the same line, infinite solutions exist (dependent). Determinant = 0 indicates these cases. Example: x + y = 1 and 2x + 2y = 2 (same line) have infinite solutions. Example: x + y = 1 and x + y = 2 (parallel) have no solution.

#### Graphical Solution
Graphing the lines shows the intersection point (solution). Two lines can intersect at one point (unique solution), be parallel (no solution), or be the same line (infinite solutions). This visual method is slower than algebra but helps intuition.

#### Three Variables
Systems with three equations and three unknowns can have unique, infinite, or no solutions. Gaussian elimination (repeated row operations) systematically solves these. With four or more equations/unknowns, matrix methods are essential.
