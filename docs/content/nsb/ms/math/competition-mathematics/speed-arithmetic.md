#### Compensation Strategy for Addition
Add 197 + 38. Instead of adding directly, add 200 + 40 = 240, then subtract the "overage" (3 + 2 = 5). Result: 240 - 5 = 235. This is faster than standard addition. The key: round to easier numbers, then adjust. Example: 496 + 387 becomes 500 + 400 = 900, minus overage (4 + 13) = 900 - 17 = 883.

#### Breaking Numbers Apart
For 457 + 238: break into hundreds (400 + 200 = 600), tens (50 + 30 = 80), ones (7 + 8 = 15). Then recombine: 600 + 80 + 15 = 695. This columnar approach is systematic and fast. Practice makes this automatic — expert calculators see numbers broken apart and combine them instantly.

#### Left-to-Right Calculation
Traditional math teaches right-to-left (units first). But mental math works left-to-right — process the largest units first, then smaller. 3,847 + 2,456: start with 3,000 + 2,000 = 5,000. Then 800 + 400 = 1,200 (running total: 6,200). Then 40 + 50 = 90 (running total: 6,290). Then 7 + 6 = 13 (running total: 6,303). Left-to-right is how the brain naturally works.

#### Subtraction and Negative Numbers
For 532 - 278, use the complement method: 532 - (300 - 22) = 532 - 300 + 22 = 232 + 22 = 254. Or recognize that 278 + ? = 532. Count up: 278 to 300 = 22, 300 to 500 = 200, 500 to 532 = 32. Total: 22 + 200 + 32 = 254. Counting-up is often faster for mental subtraction.
