#### Layer-by-Layer Summary
**Crust:** Oceanic (basalt, 7 km, 3.0 g/cm³) and continental (granite, 35–70 km, 2.7 g/cm³). Boundary with mantle = Moho. **Mantle:** 2,900 km thick, peridotite, asthenosphere (partially molten, enables plate motion) vs. rigid lithosphere. **Outer core:** liquid iron-nickel, 2,900–5,150 km, generates magnetic field via geodynamo. **Inner core:** solid iron-nickel, 5,150–6,371 km, ~5,000–6,000°C, solid due to immense pressure.

#### Critical Boundaries
| Boundary | Depth | What Changes |
|---|---|---|
| Moho | ~35 km continental, ~7 km oceanic | P-wave speed jumps; crust → mantle |
| Asthenosphere top | ~100 km | Mantle becomes partially molten |
| 660 km discontinuity | 660 km | Mineral phase change in mantle |
| Gutenberg | 2,900 km | S-waves stop; mantle → liquid outer core |
| Lehmann | 5,150 km | Solid inner core begins |

#### Wave Behavior Review
- S-waves absent beyond 103°: outer core is liquid
- P-wave shadow zone 103°–142°: core refracts P-waves away
- Faint P arrivals in shadow zone: solid inner core reflects some waves back

#### Isostasy Quick Recap
Crust floats on denser mantle. Mountains have deep roots. When load removed (deglaciation), crust rebounds. Ocean floor is lower because oceanic crust is denser than continental.

#### 15 Must-Know Facts
1. Moho named after Andrija Mohorovičić
2. Gutenberg discontinuity = mantle-outer core boundary at 2,900 km
3. Lehmann discontinuity = outer-inner core boundary at 5,150 km (discovered by Inge Lehmann)
4. Inner core = solid because pressure exceeds melting point
5. Outer core = liquid iron-nickel → generates magnetic field
6. Geothermal gradient ≈ 25–30°C/km in crust
7. Deepest borehole = Kola Superdeep, ~12 km, Russia
8. Continental crust = granite (felsic, SIAL)
9. Oceanic crust = basalt (mafic, SIMA)
10. Asthenosphere = weak, partially molten upper mantle
11. Lithosphere = rigid crust + uppermost mantle
12. Mantle = peridotite, 84% of Earth's volume
13. Earth differentiated early: iron sank, lighter rocks floated
14. Radioactive decay + primordial heat = source of geothermal energy
15. Shadow zones proved liquid outer core before it could be sampled
