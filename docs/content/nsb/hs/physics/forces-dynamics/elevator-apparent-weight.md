#### Apparent Weight Defined
A scale reads the normal force N it exerts on you, not your true weight mg. In an accelerating system, N ≠ mg. Applying ΣF = ma vertically (positive up): N − mg = ma → **N = m(g + a)**. Positive a (accelerating up) → N > mg → you feel heavier. Negative a (accelerating down) → N < mg → you feel lighter.

#### Four Elevator Scenarios
1. **At rest or constant velocity**: a = 0 → N = mg. Scale reads true weight.
2. **Accelerating upward**: a > 0 → N = m(g + a) > mg. Feel heavier.
3. **Decelerating going up (or accelerating down)**: a < 0 → N = m(g − a) < mg. Feel lighter.
4. **Free fall (a = −g)**: N = m(g − g) = 0. Weightlessness — not zero gravity, zero contact force.

#### Worked Problem
A 60 kg person in an elevator. Scale reads 720 N. Find acceleration.
N − mg = ma → 720 − 60(9.8) = 60a → 720 − 588 = 60a → 132 = 60a → a = 2.2 m/s² upward.

#### Synthesis: Newton's Laws Integration
This problem uses all three laws: First Law tells us the person moves with the elevator (same acceleration); Second Law gives ΣF = ma; Third Law explains why the scale pushes up on the person with the same force the person pushes down on the scale.

#### Review Questions
1. A 50 kg person stands in an elevator accelerating downward at 3 m/s². What does the scale read?
2. The elevator cable breaks. What does the scale read, and why?
3. In which scenario is apparent weight greater than true weight: accelerating up, moving at constant velocity upward, or decelerating while moving downward?
