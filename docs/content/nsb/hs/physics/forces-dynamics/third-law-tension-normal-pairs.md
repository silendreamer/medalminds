#### Identifying Pairs Systematically
For every force on object A from object B, there is a Third Law partner: the force on B from A. Method: state the force as "A pulls/pushes B with force F." The pair is "B pulls/pushes A with force F." Type, magnitude, and direction are dictated by the original force.

#### Three-Body System
Boxes A, B, C sit in a line on a frictionless surface. A hand pushes A, which pushes B, which pushes C.
- Hand on A (right, F_hand) → A on hand (left, F_hand)
- A on B (contact, right) → B on A (contact, left)
- B on C (contact, right) → C on B (contact, left)
Each interface has a Third Law pair. The forces on each box are not Third Law pairs with each other.

#### Common Confusion: Tension
For a string connecting two blocks: the string pulls Block 1 right (tension T) and pulls Block 2 left (tension T). Are these a Third Law pair? **No** — they act on different ends of the *string* (not the blocks), and only if the string is massless are both T. The actual Third Law pairs involve block-string interfaces: Block 1 pulls string left with T, string pulls Block 1 right with T.

#### Review Questions
1. A book sits on a table. List all Third Law pairs involving the book, table, and Earth.
2. Two ice skaters push off each other. Skater A (50 kg) accelerates at 3 m/s². Skater B has mass 75 kg. Find B's acceleration.
3. In the three-box problem above, if the applied force is 30 N and each box is 2 kg, find the contact force between B and C.
