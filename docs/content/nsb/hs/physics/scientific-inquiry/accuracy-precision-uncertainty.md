#### Accuracy vs. Precision
Accuracy describes how close a measurement is to the true value. Precision describes how close repeated measurements are to each other. A dartboard analogy: darts clustered in the bullseye = accurate and precise; darts clustered away from center = precise but not accurate; darts scattered everywhere = neither.

#### Significant Figures
Every measured quantity has limited precision. The number of significant figures (sig figs) reflects this. 12.34 cm has 4 sig figs; 0.0034 m has 2 sig figs (leading zeros don't count). When multiplying or dividing, round the answer to the fewest sig figs in the inputs.

#### Percent Error
Percent error = |experimental − theoretical| / theoretical × 100%. If you measure g = 9.4 m/s² and the accepted value is 9.8 m/s², percent error = |9.4−9.8|/9.8 × 100% = 4.1%. Always use the absolute value in the numerator.

#### Uncertainty Notation
Every measurement should be written as value ± uncertainty (e.g., 9.81 ± 0.05 m/s²). The uncertainty can come from the instrument's smallest division, from statistical spread in repeated trials, or from both. Uncertainty propagates through calculations — add absolute uncertainties when adding/subtracting; add relative (%) uncertainties when multiplying/dividing.

#### Review Questions
1. What is the difference between accuracy and precision? Give an example of each.
2. How many significant figures are in the number 0.00500?
3. A student measures the acceleration due to gravity as 9.6 m/s². The accepted value is 9.81 m/s². Calculate the percent error.
