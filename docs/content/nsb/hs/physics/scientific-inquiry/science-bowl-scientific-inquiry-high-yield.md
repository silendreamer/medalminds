#### High-Yield Fact List
1. **Falsifiable** = the key word for a valid scientific hypothesis.
2. **Independent variable** = what the experimenter changes (controlled by experimenter).
3. **Dependent variable** = what is measured (responds to the independent variable).
4. **Percent error formula** = |exp − theo| / theo × 100%.
5. **Systematic error** = consistent shift in one direction (doesn't cancel with averaging).
6. **Random error** = scatter around true value (reduced by averaging).
7. **Accuracy** = closeness to true value; **Precision** = reproducibility.
8. **Significant figures** in multiplication: use the fewer sig figs of the inputs.
9. **Control group** = the untreated baseline group.
10. **Mean** = sum of values ÷ number of values.
11. **Standard deviation** = measure of spread; small SD = precise.
12. **Peer review** = expert evaluation before publication.
13. **Reproducibility** = same result across different labs.
14. **Confounding variable** = uncontrolled variable that affects the result.
15. **Uncertainty** is written as ± (e.g., 9.81 ± 0.05 m/s²).

#### Practice Toss-Up Stems
1. "For 10 points — in an experiment, this type of variable is what the experimenter deliberately changes." *(Answer: independent variable)*
2. "For 10 points — this percentage measures how far an experimental result deviates from the accepted theoretical value." *(Answer: percent error)*
3. "For 10 points — this type of error shifts all measurements consistently in one direction and cannot be reduced by taking more trials." *(Answer: systematic error)*

#### Review Questions
1. What is the percent error if you measure 9.4 m/s² for g (accepted = 9.81 m/s²)?
2. Name the two qualities of a good scientific hypothesis.
3. What distinguishes precision from accuracy?
