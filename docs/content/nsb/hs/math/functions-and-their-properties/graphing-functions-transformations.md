### Introduction to Functions and Their Graphs  
Functions are mathematical relationships that assign each input exactly one output. Graphing a function involves plotting points on a coordinate plane where the x-coordinate represents the input and the y-coordinate represents the output. Understanding how to graph functions is essential for analyzing their behavior and properties, which can be further explored through transformations.

### Basic Graphing Techniques  
To graph a function, one can start by creating a table of values, selecting various x-values, and calculating the corresponding y-values. Plot these points on a Cartesian plane and connect them to visualize the function's shape. Common functions include linear, quadratic, and exponential functions, each with distinct characteristics that can be identified through their graphs.

### Vertical and Horizontal Shifts  
Transformations of functions can be categorized into shifts, stretches, and compressions. A vertical shift occurs when a constant is added to or subtracted from the function, resulting in the graph moving up or down. For example, the function \( f(x) = x^2 \) becomes \( f(x) = x^2 + 3 \), shifting the graph up by 3 units. Conversely, a horizontal shift occurs when a constant is added to or subtracted from the input, moving the graph left or right, as seen in \( f(x) = (x - 2)^2 \), which shifts the graph 2 units to the right.

### Stretching and Compressing Functions  
Stretching and compressing transformations alter the shape of the graph without changing its position. A vertical stretch occurs when the function is multiplied by a factor greater than 1, making the graph taller. For instance, \( f(x) = 2x^2 \) stretches the graph of \( x^2 \) vertically by a factor of 2. In contrast, a vertical compression happens when the factor is between 0 and 1, such as \( f(x) = 0.5x^2 \), which compresses the graph toward the x-axis.

### Combining Transformations  
Functions can undergo multiple transformations simultaneously, which can be combined in a single equation. For example, the function \( g(x) = -3(x + 1)^2 + 4 \) represents a graph that is shifted left by 1 unit, stretched vertically by a factor of 3, and reflected across the x-axis, then shifted up by 4 units. Understanding how to apply these transformations in sequence is crucial for accurately graphing more complex functions.

### Analyzing Function Properties  
When graphing functions, it is important to analyze their properties, such as intercepts, symmetry, and end behavior. The x-intercepts are found where the graph crosses the x-axis, while the y-intercept is where it crosses the y-axis. Symmetry can indicate whether a function is even or odd, affecting how the graph behaves. End behavior describes how the function behaves as x approaches positive or negative infinity, which can be determined from the leading term in polynomial functions.
