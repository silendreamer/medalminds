#### Side-by-Side Comparison
| Feature | GPCR | RTK | Ligand-gated channel |
|---|---|---|---|
| Ligand type | Peptides, amines, odorants | Growth factors | Neurotransmitters |
| Second messenger | cAMP, IP₃, DAG | Phosphotyrosine | None (direct) |
| Speed | Seconds | Minutes–hours | Milliseconds |
| Key effector | PKA, PKC | RAS, PI3K | Ion flux |
| Typical response | Metabolism, secretion | Growth, differentiation | Electrical signaling |

#### Convergence on Shared Effectors
Different receptor types often converge on the same downstream effector. Both RTKs and GPCRs can activate PI3K, which produces PIP₃ and activates AKT. AKT promotes cell survival, growth, and glucose uptake. This convergence means that multiple extracellular signals can reinforce the same intracellular decision — a robust system for critical cellular choices.
