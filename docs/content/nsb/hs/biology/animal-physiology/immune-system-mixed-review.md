#### Integration Questions
Immune responses occur in layers: a pathogen first encounters physical barriers → if breached, innate immune cells respond (minutes to hours, non-specific) → dendritic cells present antigens to T cells in lymph nodes → adaptive response begins (days) → B and T cell clonal expansion → primary immune response → memory. Second exposure: memory cells respond within 1–3 days (faster than adaptive primary response, but not as fast as innate).

Connecting concepts: Complement is part of **innate** immunity but can be activated by **antibodies** (classical pathway) — a bridge between innate and adaptive. NK cells are **innate** but are activated more effectively in the presence of antibodies (antibody-dependent cellular cytotoxicity, ADCC). Innate and adaptive immune systems are not separate — they communicate extensively via cytokines.

#### Review Questions
1. A patient is deficient in CD4+ helper T cells. Predict the effects on both B cell antibody production and CD8+ cytotoxic T cell activity, and explain why.
2. Compare the roles of memory B cells and plasma cells following a primary immune response. Which is responsible for long-term protection?
3. A researcher develops a new vaccine using mRNA encoding a viral surface protein. Trace the entire immune response from injection to establishment of immunological memory.
