#### Review: Core Concepts at a Glance
- **Independent variable**: what you change deliberately
- **Dependent variable**: what you measure in response
- **Controlled variables**: everything held constant
- **Hypothesis**: testable, falsifiable prediction with mechanism
- **Accuracy**: closeness to true value (addressed by calibration)
- **Precision**: reproducibility (addressed by technique)
- **Systematic error**: consistently off in one direction; more trials don't help
- **Random error**: scatter; reduced by averaging more trials
- **% error** = |exp − theo| / theo × 100%

#### Scenario Classification Practice
Classify each as systematic or random error, and predict direction (too high/low/neither):
1. A balance reads 0.3 g when nothing is on it (not zeroed before use) → Systematic; all measurements 0.3 g too high
2. A student reads burette volume slightly differently each time → Random; scatter in both directions
3. A thermometer consistently reads 1.5°C above true temperature → Systematic; all temperature readings too high
4. Slight variation in stirring speed between trials → Random

#### Control Group Identification
Which of these experiments has a properly designed control?
(A) Testing 3 different acid concentrations with no plain water trial — No control
(B) Testing 3 acid concentrations plus one trial with distilled water (no acid) — Yes, correct control
(C) Testing 2 different catalysts plus one trial with no catalyst — Yes, correct control

#### Review Questions
1. A student measures pH as 4.1, 4.2, 4.1, 4.3, 4.0. The true pH is 7.0. Describe the precision and accuracy, name the error type, and suggest a cause.
2. An experiment has a control group that receives the solvent (water) but not the dissolved reactant. In a second experiment, there is no control group at all. Which is valid? Why?
3. What is the percent error if the experimental molar heat of fusion of ice is 5.90 kJ/mol and the accepted value is 6.01 kJ/mol?
