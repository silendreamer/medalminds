#### Top 15 Bowl-Ready Facts
1. Independent variable = what the experimenter changes
2. Dependent variable = what is measured
3. A hypothesis must be testable AND falsifiable
4. Percent error = |exp − theo| / theo × 100%
5. Accuracy = closeness to true value; precision = reproducibility
6. Systematic error cannot be reduced by more trials; random error can
7. A control group lacks the independent variable treatment
8. In chemistry, a "theory" is a well-substantiated explanation (not a guess)
9. A scientific law describes what happens; a theory explains why
10. Parallax error: reading a scale from an angle causes systematic error
11. Bomb calorimeter eliminates heat-loss error by using a sealed vessel
12. Replication by independent labs is the strongest evidence for a finding
13. Standard deviation quantifies the spread (precision) of data
14. The scientific method produces tentative conclusions, never absolute proof
15. Peer review requires expert evaluation before publication — but does not guarantee correctness

#### Common Toss-Up Clue Phrases
- "This type of error consistently shifts results in one direction…" → systematic error
- "This value describes how repeatable an experiment is…" → precision
- "Named after the scientist who first proposed electrons exist as probability clouds…" → Schrödinger
- "This group in an experiment receives no treatment…" → control group

#### Practice Toss-Up Stems
1. "For 10 points — what term describes the variable a scientist deliberately changes in a controlled experiment?" → **independent variable**
2. "For 10 points — a student's measurements cluster tightly but are all 15% above the true value. What type of error is this?" → **systematic error**
3. "For 10 points — what calculation gives the percentage difference between an experimental result and the accepted value?" → **percent error**

#### Review Questions
1. What distinguishes a scientific theory from a hypothesis?
2. Why is peer review necessary but not sufficient for scientific truth?
3. A student's percent error is 0.2% but every trial gives the same wrong answer. Is the experiment precise? Accurate? What type of error is present?
