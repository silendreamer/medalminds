#### Step 1: Classify the Compound
Before naming, determine: (A) metal + nonmetal → ionic; (B) nonmetal + nonmetal → covalent/molecular; (C) starts with H dissolved in water → acid; (D) contains NH₄⁺ → ammonium salt (ionic).

#### Worked Examples
- Mg₃N₂: Mg (metal) + N (nonmetal) → ionic; Mg is always 2+; N must be 3− (−6 total balanced by +6 from 3 Mg²⁺) → magnesium nitride
- N₂H₄: two nonmetals → covalent → dinitrogen tetrahydride (also called hydrazine, a common name)
- HClO₃(aq): oxyacid; ClO₃⁻ = chlorate → chloric acid
- Fe₂(SO₄)₃: Fe cation + SO₄²⁻; three SO₄²⁻ = −6, so two Fe = +6, each Fe³⁺ → iron(III) sulfate

#### Name to Formula Practice
- Cobalt(II) nitrate: Co²⁺ and NO₃⁻ → Co(NO₃)₂
- Dichlorine heptoxide: Cl₂O₇
- Phosphoric acid: H₃PO₄

#### Review Questions
1. Classify and name: SnO₂, HBr(aq), (NH₄)₂CO₃, SF₆.
2. Write formulas for: manganese(IV) oxide, hydriodic acid, iron(III) sulfite.
3. A compound has formula CrCl₃. Identify the oxidation state of chromium and name the compound.
