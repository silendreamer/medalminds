#### Variety of Balancing Problems
- Simple binary: N₂ + O₂ → NO₂ (Answer: 2N₂ + 4O₂ → 4NO₂)
- With polyatomic: NH₄NO₃ → N₂O + H₂O (Answer: NH₄NO₃ → N₂O + 2H₂O, no coefficient)
- Combustion: C₄H₁₀ + O₂ → CO₂ + H₂O (Answer: 2C₄H₁₀ + 13O₂ → 8CO₂ + 10H₂O)
- Redox: Fe + Cl₂ → FeCl₃ (Answer: 2Fe + 3Cl₂ → 2FeCl₃)

#### Common Traps
- Forget to balance one element (check all atoms!)
- Leave fractional coefficients
- Change subscripts instead of coefficients
- Miscount atoms in compounds with multiple of an element (e.g., Ca(OH)₂ has 2 O and 2 H, not 1 each)

#### Self-Check Technique
After balancing, make a table: C | H | O (or whatever elements). Left side: list coefficients × atoms per molecule. Right side: same. All rows should match.

#### Review Questions
1. Balance: MnO₂ + HCl → MnCl₂ + Cl₂ + H₂O
2. Balance: Al + O₂ → Al₂O₃
3. Balance: K + H₂O → KOH + H₂
