#### Quick Reference: Each Model's Core Claim
- **Dalton:** Atoms are indivisible; identical atoms per element; fixed ratios in compounds
- **Thomson:** Atoms contain electrons; positive charge is diffuse (plum pudding)
- **Rutherford:** Nucleus is tiny, dense, positive; atom is mostly empty space
- **Bohr:** Electrons in fixed quantized orbits; energy levels determine spectra
- **Quantum/Schrödinger:** Electrons in probability orbitals; described by wave functions

#### Cross-Model Practice
Q: Which models can explain why atoms of different elements have different chemical properties? A: All models, because they all recognize that different elements have different atoms — but only models from Bohr onward explain *why* at the electron-structure level.

Q: Which model first explained why excited hydrogen emits light at discrete wavelengths? A: Bohr's model — electrons in quantized orbits emit specific-energy photons when dropping from high n to low n.

#### Review Questions
1. Arrange the following in chronological order: Schrödinger, Thomson, Dalton, Bohr, Rutherford. Briefly state each scientist's key contribution.
2. What single experimental result could NOT be explained by both the plum pudding model and Rutherford's model? What was that result, and which model resolved it?
3. A student says "electrons orbit the nucleus like planets orbit the sun." Which atomic model does this describe, and what modern evidence contradicts it?
