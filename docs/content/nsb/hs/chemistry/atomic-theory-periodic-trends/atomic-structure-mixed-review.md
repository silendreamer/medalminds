#### Rapid Fire: True or False?
1. Isotopes of the same element have different numbers of protons. → FALSE (same protons, different neutrons)
2. The mass number is always a whole number. → TRUE
3. An anion has more electrons than protons. → TRUE
4. The atomic mass on the periodic table equals the mass number of the most stable isotope. → FALSE (it is a weighted average)

#### Short Calculation
Magnesium has three isotopes: ²⁴Mg (23.985 amu, 78.99%), ²⁵Mg (24.986 amu, 10.00%), ²⁶Mg (25.983 amu, 11.01%). Atomic mass = (23.985)(0.7899) + (24.986)(0.1000) + (25.983)(0.1101) = 18.945 + 2.499 + 2.861 = 24.305 amu ≈ 24.31 amu.

#### Review Questions
1. Which subatomic particle contributes most to the mass of an atom but least to its chemical behavior?
2. The element with atomic number 17 and mass number 35 forms a −1 ion. Write its nuclear notation and state how many of each subatomic particle it contains.
3. If an element has three isotopes with masses 63.93 amu (69%), 65.93 amu (4%), and 67.93 amu (27%), estimate its atomic mass.
