#### Orbital Diagram Conventions
Draw sublevels as boxes; electrons as arrows (↑ for +½, ↓ for −½). Place one electron in each orbital of a sublevel before pairing. All single electrons should have same spin (conventionally shown as ↑).
Example — Carbon (1s²2s²2p²):
1s: [↑↓] 2s: [↑↓] 2p: [↑][↑][ ]

Example — Nitrogen (1s²2s²2p³):
1s: [↑↓] 2s: [↑↓] 2p: [↑][↑][↑]

Example — Oxygen (1s²2s²2p⁴):
1s: [↑↓] 2s: [↑↓] 2p: [↑↓][↑][↑]

#### Review Questions
1. Draw the orbital diagram for sulfur (Z=16) and identify how many unpaired electrons it has.
2. An element has two unpaired 3d electrons. Write a possible electron configuration consistent with this.
3. Explain why Hund's rule results in lower energy arrangements than pairing electrons in the same orbital.
