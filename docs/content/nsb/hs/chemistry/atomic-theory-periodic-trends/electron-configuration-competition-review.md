#### Speed Drill: Write the Configuration
- Na (Z=11): [Ne] 3s¹
- Cl (Z=17): [Ne] 3s² 3p⁵
- Ca (Z=20): [Ar] 4s²
- V (Z=23): [Ar] 4s² 3d³
- Cr (Z=24): [Ar] 4s¹ 3d⁵ (exception!)
- Cu (Z=29): [Ar] 4s¹ 3d¹⁰ (exception!)
- Zn (Z=30): [Ar] 4s² 3d¹⁰
- Br (Z=35): [Ar] 4s² 3d¹⁰ 4p⁵

#### Ion Drill
- Na⁺: [Ne] (lost 3s¹)
- Mg²⁺: [Ne]
- Al³⁺: [Ne]
- O²⁻: [Ne] (gained 2e → 1s²2s²2p⁶)
- Fe²⁺: [Ar] 3d⁶
- Fe³⁺: [Ar] 3d⁵

#### Review Questions
1. Write the electron configuration for Mn²⁺ and state how many unpaired electrons it has.
2. Identify the element with configuration [Xe] 6s² 4f¹⁴ 5d¹⁰ 6p⁴.
3. Which element in period 4 has the highest number of unpaired electrons in its ground state, and what is that configuration?
